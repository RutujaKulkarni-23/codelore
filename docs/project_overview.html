Function-Aware AST-Hybrid Chunking Mechanics

Rather than slicing text blindly by fixed character windows, CodeLore uses Python AST to preserve complete grammatical functions and classes. Chunks only window when an individual function exceeds 60 lines or 3,000 characters.

Deterministic Request Lifecycle Flow

Deterministic Callback Verified

The Engineering Solution to Small-Model Refusal Loops

During live evaluation of 11B parameter models, the chat model frequently ignored valid tool outputs, initiating 15-call runaway hallucination loops. CodeLore resolves this via an architectural hybrid pattern:

1. State Writing in Tool

Tools write copy-ready markdown citations into state["temp:final_text"] and set skip_summarization = True.

2. Turn Interception

The ADK codelore_after_agent_callback detects temp:final_text and delivers it directly to the user, completely bypassing model generation.

3. Execution Loop Guard

loop_guard_before_tool_callback blocks a 3rd call to the same tool or any repeat call with identical arguments, halting runaway loops.

Instructor Q&A & Technical Defense

15 Defended Answers
1. Why is the Boss agent prohibited from calling tools directly?
Giving tools to the Boss causes the coordinator to attempt speculative queries or answer prematurely. Enforcing zero tools guarantees single-responsibility intent classification and delegation via transfer_to_agent (code_helper/agent.py:189).
2. How do you prevent infinite transfer loops between agents?
Workers are instantiated with disallow_transfer_to_parent=True and disallow_transfer_to_peers=True (code_helper/agent.py:138-139). Agent transfer is strictly one-way from Boss to the designated specialist.
3. What is the difference between Document RAG and Code RAG?
Document RAG splits text by sentence or token count. Code RAG must respect language syntax: splitting a Python function in half breaks arguments, indentation, and variable scope, resulting in invalid citations.
4. What chunking strategy is implemented and why?
ast_hybrid chunking (code_helper/rag/chunker.py:114). It creates one chunk per top-level function or class, windowing only oversized blocks (>60 lines or >3000 chars) with an 8-line overlap to preserve boundary context.
5. How did you solve the small-model tool refusal loop?
Exact lookup tools store copy-ready citations into state["temp:final_text"] with skip_summarization = True. The ADK callback codelore_after_agent_callback delivers this text directly to the user, completely bypassing model generation (code_helper/agent.py:80-91).
6. How does the loop guard protect against runaway API billings?
loop_guard_before_tool_callback tracks per-turn tool invocations. It blocks a 3rd call to the same tool or any repeated call with identical arguments, injecting a stop instruction (code_helper/agent.py:35-62).
7. Why does the embedder use asymmetric input types?
NVIDIA's nemotron-3-embed-1b model uses asymmetric pooling: input_type="passage" optimizes internal attention for long code definitions during indexing, while input_type="query" optimizes for short search queries during retrieval.
8. How was MIN_SCORE = 0.35 calibrated?
Calibrated empirically across 16 queries in eval_runs/min_score_calibration.md. 0.35 is the midpoint between the highest irrelevant query score (0.3016 for Slack webhook) and the lowest true code query (0.4049).
9. What prevents path traversal attacks like ../../etc/passwd?
safe_resolve() resolves target paths and verifies they remain children of target_root. It rejects .., drive letters, colons, and Windows reserved device names with a PathSecurityError (code_helper/tools/_paths.py:13-48).
10. How do you prevent leaking API keys to the MCP subprocess?
build_filesystem_toolset() sanitizes the child environment dictionary, passing only safe OS keys (PATH, SystemRoot, TEMP, USERPROFILE). NVIDIA and Pinecone keys are explicitly excluded (code_helper/mcp_config.py:35-46).
11. Why use Python AST instead of regular expressions?
Regex cannot track multi-line function headers, nested classes, async defs, decorators, or parent-child scopes accurately. AST provides exact compiler-verified start and end line coordinates.
12. Does Filesystem MCP count toward the five custom tools?
No. Filesystem MCP is an external Node.js subprocess protocol server. CodeLore implements six custom Python tools separately.
13. What is CodeLore's retrieval performance on Naive_RAG?
Retrieval achieves 80% Hit@1, 90% Hit@3, and 100% Hit@5 across the 10 answerable target analysis questions in eval_runs/min_score_calibration.md.
14. What is a known failure mode of the current implementation?
When the 11B chat model reads source text mentioning a function name, it occasionally hallucinates that the target function is an agent tool and attempts to call it (e.g. calling chunk_document() as a tool), triggering a tool-not-found error (docs/known_limitations.md:12-19).
15. Is Hybrid Retrieval implemented in CodeLore?
No. Retrieval is pure dense vector retrieval via Pinecone. CodeLore implements AST-Hybrid Chunking, but true Hybrid Retrieval (BM25 + vector rank fusion) is planned for Phase 10.
